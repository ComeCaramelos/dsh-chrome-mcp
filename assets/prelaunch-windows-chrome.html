Keep this window open. It is not a browsing session you started — closing it drops the debugging session, and the agent has to open a new one. The plugin never closes it: closing it is yours to do.

Why this window exists

A plugin running inside DSH on WSL started this browser on the Windows side so an agent can drive it over the DevTools debugging protocol. The bridge cannot launch the browser itself: a Windows chrome.exe started across the WSL interop boundary cannot carry its debugging pipes, so the only working Windows path is to open the window here and have the bridge connect to it.

Nothing is browsed, submitted or uploaded on its own — every action comes from a tool call.
